# 0.4.0 — 2026-11-01

- Kill switch для TUN. Помощник joxy-guard (Go, свой код) ставит правила WFP в динамической сессии: при включённом VPN весь трафик мимо Xray и адаптера JOXY блокируется. Разрешены loopback, DHCP/NDP и, при обходе локальной сети, LAN кроме DNS к роутеру. Выключен по умолчанию.
- Блокировка сохраняется при автоматическом переподключении, смене сети и падении ядра. Ручное «Отключиться», неудачная первая попытка подключения, выключение настройки и закрытие JOXY её снимают. На экране подключения есть кнопка «Снять блокировку».
- Адрес сервера резолвится до включения блокировки и кэшируется, чтобы переподключение работало без системного DNS.
- Ядро Xray после неожиданного завершения перезапускается автоматически во всех режимах.

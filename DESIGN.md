# Дизайн JOXY 0.6.0 — по прототипу пользователя

Источник: четыре экрана прототипа (без локации, локация выбрана, подключено, настройки).

- Один экран. Сверху слева локация («Страна · сервер ▾»), справа «Настройки». В центре точечная карта мира, под ней статус, таймер `--:--:--`/`00:16:42` (Geist Mono), круглая кнопка 72 px. Внизу три колонки: протокол, ↓, ↑.
- Состояния карты: серые точки → выбранная страна тёмная → при подключении карта приближается к стране и точки зелёные; кнопка и точка статуса тоже зелёные.
- Палитра: белый/графит днём, `#111214` ночью; зелёный `#16a34a`/`#22c55e` — единственный цвет-сигнал.
- Настройки: «← Настройки», слева разделы, справа строки «название + пояснение + переключатель», тема сегментами.
- Движение (навык apple-design): отклик на нажатие сразу; пружины с damping 1.0 через `linear()`; приближение карты на transform; список локаций раскрывается из кнопки; reduced motion отключает приближение.
- Карта собирается скриптом `scripts/build-world-dots.mjs` из Natural Earth (общественное достояние).

Скриншоты: `docs/screenshots/`. Обновить: `npm run shots`.

# Дизайн JOXY 0.5.0 — «посадочный талон»

Идея: подключение к VPN — это поездка за границу. Текущая сессия показана как посадочный талон, серверы — как табло вылетов. Тема живёт в облике, а подписи остаются прямыми («Подключиться», «Задержка»), чтобы не жертвовать ясностью.

- Талон: «Откуда» — ваша сеть, «Куда» — код и название страны. Пунктирный маршрут заполняется при подключении; по нему летит точка, она садится при успехе. Корешок отделён перфорацией с вырубками, на нём флаг, штамп статуса, штрихкод (стабильный для профиля) и главное действие.
- Палитра: бумага `#f2efe8` и чернила `#16171a`; ночью `#0f1012` и `#f1eee6`. Сигнальный оранжевый (`#ff5a1f` / `#ff6a2c`) — только маршрут, выбор, фокус и переключатели. Основные кнопки чернильные: белый текст на оранжевом не держит контраст мелкого текста.
- Типографика: Golos Text для текста, Geist Mono для подписей-капителей (разрядка 0,12em) и чисел; крупные коды страны с трекингом −0,035em. Трекинг и интерлиньяж зависят от размера.
- Движение (навык apple-design): обратная связь на нажатии; пружины с damping 1.0 без отскока, в CSS через `linear()` по точной формуле, прерываемые переходы на transform/opacity; reduced motion, reduced transparency и повышенный контраст поддержаны.

Скриншоты: `artifacts/design-0.5.0/`. Обновить: `npm run shots`.

# ZAGRAN 0.1.1

Интерфейс настольной утилиты. Главная задача экрана — выбрать соединение, понять его состояние и подключиться.

## Изменения после первой версии

- Убраны рекламный заголовок, подписи капсом, орбиты, огромная кнопка питания и декоративные цветные карточки.
- Статус, выбор сервера и параметры текущей сессии сгруппированы в одной панели.
- Основное действие — обычная кнопка «Подключиться» с мгновенной реакцией на нажатие.
- Серверы представлены списком с единым оформлением, понятным выбором и реальным результатом проверки.
- Статистика показывается во время подключения, график раскрывается отдельно. Пустого графика на стартовом экране нет.
- Настройки организованы группами строк. Второстепенные пояснения имеют достаточный контраст и обычный регистр.
- Ошибка импорта связана с конкретным полем и отображается внутри диалога. Поддерживаются Escape, фокус ввода и замкнутый порядок Tab.
- Тема следует системе; предусмотрены reduced motion, reduced transparency и повышенный контраст.
- На Windows используются Segoe UI и привычное расположение оконных кнопок. Шрифты SF и иконки SF Symbols не распространяются.

## Основа

Использован независимый навык `apple-design` от Emil Kowalski:
https://github.com/emilkowalski/skills/tree/main/skills/apple-design

Навык установлен локально у автора. Он не включён в распространяемое приложение. Это сторонний материал, не официальный продукт Apple.

Применённые принципы: простота, конкретные подписи, знакомые модели взаимодействия, типографическая иерархия, немедленная обратная связь, сдержанное движение. Движение не блокирует ввод. Размытие ограничено оконной панелью над прокручиваемым содержимым.

Это адаптация принципов для Windows, а не заявление о сертификации Apple HIG. Прежний вариант сохранён в `artifacts/design-0.1.0/` для сравнения.
